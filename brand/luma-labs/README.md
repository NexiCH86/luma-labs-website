# LuMa Labs — Definitive Logo Master Library

Status: **Definitive / verbindlich**  
Master concept: **LM MONOGRAM**  
Created: 2026-08-29

Diese Brand-Library ist die zentrale **Single Source of Truth** für das LuMa-Labs-Logo.

## Primary identity
- Brand name: **LuMa Labs**
- Signet: geometric **LM monogram**
- Primary usage: dark graphite background + cyan/petrol LM signet + off-white wordmark
- Tagline: **Engineering tomorrow.**
- Extended line: **Connecting Engineering, Software & Smart Infrastructure.**

## Master colors
- LuMa Graphite: `#071117`
- LuMa Cyan: `#00D7E6`
- LuMa Petrol/Cyan Dark: `#00AFC2`
- Off White: `#F4F6F8`
- Ink: `#0A1116`
- Supporting Slate: `#9DA8AE`

## Typography
- Primary: **Inter**
- Wordmark weight: 300 / Light
- Supporting text: 400 / Regular

## Usage priority
1. `master/LuMaLabs_MASTER_Horizontal_Dark.svg`
2. `master/LuMaLabs_MASTER_Horizontal_Light.svg`
3. `master/LuMaLabs_MASTER_Signet_Gradient.svg`
4. Mono versions for restricted print
5. E-Ink version for LuMa Slate

## Rules
- Do not stretch or distort.
- Do not rotate the signet.
- Keep generous clear space around the logo.
- Do not add shadows, outlines or additional colors to the master mark.
- For very small UI sizes, use the signet without the wordmark.
- For E-Ink, use the pure black Slate variant.

## Repository policy
All LuMa projects should reference or copy assets from this directory. Any future logo revision must be made here first and then propagated to downstream projects.

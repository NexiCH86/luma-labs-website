# LuMa Labs — LM Monogram App Icon System

Version 1.0 — 30 August 2026

## Binding design rule
The LM Monogram is the parent brand. Every LuMa Labs product or service keeps the same LM geometry and receives exactly one product glyph in the reserved upper-right area.

## Current family
- LuMa Slate — layers / E-Ink workspace
- BOG Fusion — cube / BIM & collaboration
- LuMa AI — network / local AI
- LuMa Air — airflow
- LuMa Academy — graduation cap
- LuMa Docs — document
- LuMa Server — server
- LuMa Sync — sync arrows
- LuMa Home — globe / homepage
- LuMa Radar — radar target
- LuMa Cloud — cloud
- LuMa Security — shield
- LuMa API — plug
- LuMa Support — support ring

## Variants
Dark is the digital standard. Light, monochrome, inverted and E-Ink variants are included in the downloadable master package.
SVG is the canonical master format; PNG exports are convenience assets.

## Important
This is the approved LuMa Labs product-icon system based on the definitive LM Monogram.
The artwork is a clean vector reconstruction of the approved visual system and should remain the canonical source for future refinements.
